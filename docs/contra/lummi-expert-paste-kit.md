## 1. Service — Lummi Visuals for Your Framer Site

**Where:** Profile → Services → New service (or Products/Services).

| Field | Value |
|---|---|
| Title | `Lummi Visuals for Your Framer Site` |
| Subtitle | `A small branded image set in Lummi — ready to drop into Framer, not generic stock.` |
| Type | Inquire first · Starting at **$100** |
| Duration | 2–4 days |
| Role tags | Framer Designer, Visual Designer |
| Tool tags | **Lummi**, Framer |
| Cover | Grid of 4 stills: `03`, `06`, `07`, `08` (or `02`) |

**Description (paste):**

```
**For who**
You have a Framer site or template and the photos are the weak part — dummy stock, empty frames, or nothing that matches the brand.

I generate a tight set in Lummi and hand it off so you can place it — or I place it if we’re already on the site.

**What you get**
A branded image set: same look, same light, usable on web. Not a hundred random outputs. A few strong frames you’d actually publish.

**What’s included**
• Short brief: subject, mood, palette, where they’ll live on the site
• 8 images in Lummi, selected from a wider batch
• 2 rounds of direction (regenerate / pick, not a new brand)
• Exports sized for web (hero + supporting)
• A simple board so you can see the set together

**Not included**
• Full site design or template customization (those are other services)
• Print campaigns, ads, or video
• Unlimited generations
• Copy or layout

**Result**
Visuals that feel like the brand, ready for Framer.

**What I need from you**
Brand (logo, colors, type), 3–5 references, and where each image goes (hero, about, cards, etc.).
```

**FAQs (one field each):**

1. **Is this a website?**  
   No. Images only. If you need them placed in Framer, say so — that’s a light add-on or part of the design / template service.

2. **What is Lummi?**  
   An AI image tool. I use it to build a consistent set for your brand, not one-off stock.

3. **How many images is $100?**  
   Eight web-ready stills from one direction, plus two rounds. More frames, a second style, or on-site placement are quoted.

4. **Can I use them commercially?**  
   Yes, for your site and brand, within Lummi’s license. I’ll flag anything that doesn’t fit.

5. **How long?**  
   About 2–4 days after the brief is clear.

**Example work:** link CS1 and CS2 after they are live.

Publish. Confirm the service shows **Lummi** as a tool.
