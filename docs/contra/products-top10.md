## Delivery rule (important)

For **Marketplace components**, After purchase must deliver the **Component URL** (`framer.com/m/...`), not a remix.

| Type | What it is | For components? |
|------|------------|-----------------|
| **Component URL** | Assets → Copy URL → paste into any project | **Yes — canonical** |
| **Live preview** | `framer.link` / `*.framer.app` demo | Description only |
| **Remix link** | File → Copy Remix Link (`?duplicate=…`) | Templates / optional demo project — **not** default for components |
| **Project URL** | `framer.com/projects/Name--id-…` | Editor only — **buyers cannot open** |

Do **not** put Project URLs in After purchase. If you want a remix, generate it in Framer (File → Copy Remix Link) and paste that — never the editor project link.
