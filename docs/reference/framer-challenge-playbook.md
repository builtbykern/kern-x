# #FramerChallenge Engagement Playbook

Use this as a focused Accio Work skill when `#FramerChallenge` is active.

## Goal

Support challenge participants in a way that earns relevant visibility from builders,
designers, and Framer creators. `@builtbykern` does not participate in the challenge.
The agent should never imply participation.

## Search queries

Use a 4-8 hour window:

- `#FramerChallenge`
- `"Framer Challenge"`
- `"FramerChallenge"`
- `Framer challenge submitted`
- `Framer challenge day`
- `Framer challenge build`
- `Framer challenge learned`

## Priority candidates

Reply first to posts with:

1. Screenshot, video, prototype, or live demo.
2. Progress update: `day X`, `submitted`, `accepted`, `shipped`, `learned`.
3. Specific implementation note: layout, breakpoints, motion, interaction, CMS, category.
4. Small or mid-size creator with genuine activity and low reply count.

Skip posts that are only:

- generic hype;
- follow bait;
- off-topic design drama;
- unclear screenshot with no context;
- requests for harsh critique.

## Reply style

Support must be specific and observational:

- mention `responsive breakpoints`, `layout rhythm`, `motion timing`, `interaction idea`,
  `category fit`, `content structure`, or `build consistency` when observable;
- use lowercase starts when natural;
- keep the response short unless there is a real technical point;
- do not overpraise.

## Good pattern

```text
[specific observation]. [why it matters for the build / challenge / user experience]
```

Examples for rhythm only:

```text
the layout rhythm makes the section feel easier to scan

shipping during a challenge is a strong signal. the interaction idea feels focused

the responsive handling is doing a lot of work here
```

## Hard rules

- No emojis.
- No exclamation marks.
- No self-promotion.
- No links.
- No asking for follows.
- No saying `we are also participating`.
- No harsh critique unless the author explicitly asks and the owner has approved.
- Do not compare one participant against another.

## Volume

Within the global daily reply cap:

- normal day: 6-12 `#FramerChallenge` replies;
- very active challenge window: up to 15, only if quality stays high;
- do not reply to the same participant again within 48 hours.

## End-of-cycle log

Report:

- posted reply URLs;
- skipped candidates with reason: `dup`, `thin`, `off-topic`, `too promo`, or `critique risk`.
