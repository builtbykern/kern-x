# Scroll Story Stage

**Category:** Interactions  
**Price:** $19 (lite free tip optional)  
**Byline:** Cinematic scroll storytelling for SaaS & portfolios

## Marketplace description

Scroll Story Stage turns a tall section into a sticky cinematic stage. As visitors scroll, scenes zoom, curtain, or slice into focus — one story beat at a time.

Built for product launches, agency case-study pages, and portfolio heroes that need motion without a custom code project.

### Modes
- **Zoom** — media eases from oversized to framed
- **Curtain** — scenes wipe in with configurable overlap
- **Slice** — angled lateral reveals with subtle skew

### Features
- Sticky stage with configurable section height (vh)
- Up to 8 scenes (title, caption, image)
- Progress bar + scene dots
- Offscreen pause via IntersectionObserver
- Respects `prefers-reduced-motion` (+ Force Static toggle)
- Full color controls for brand matching

### Best used for
- SaaS product storytelling
- Agency / studio case study pages
- Portfolio project highlights

## Setup
1. Add `ScrollStoryStage.tsx` to your Framer Code folder
2. Drop the component onto the canvas
3. Set Mode, add Scenes, tune Height (vh)
4. Publish a focused live preview with a single instance

## Thumbnail guidance
One sticky frame mid-zoom. No logos, no multi-component collage, no decorative text overlays.
