# Stat CountUp

**Category:** Data  
**Price:** Free or $5  
**Byline:** Clean metric counter for SaaS & portfolio stats

## Description

Stat CountUp animates a number from `from` to `to` once when it enters the viewport. Built for metric rows on SaaS landings, agency results, and crowdfunding pages.

### Features
- Prefix / suffix (`$`, `%`, `+`)
- Decimals and thousand separators
- Typography controls (font, size, weight, color, align)
- Triggers once at ~40% in view
- Respects `prefers-reduced-motion`

### Not included (by design)
Loader pacing, K/M/B auto-shorten, color fades, rolling 3D digits, replay loops.

## Setup
1. Paste `StatCountUp.tsx` into Framer → Assets → Code
2. Drop on canvas, set From / To / Duration
3. Style prefix, suffix, and type

## Acceptance
- Enters view → counts to exact `to`
- Reduced motion → shows final value immediately
- Single self-contained `.tsx`
