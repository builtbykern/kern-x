# CMS Spotlight Gallery

**Category:** Carousels / Interactions  
**Price:** Free (views) or $9 premium with polish  
**Byline:** CMS-native horizontal gallery with sticky active titles

## Marketplace description

CMS Spotlight Gallery is a production-safe horizontal spotlight for Framer CMS collections. Drag, swipe, snap, and keyboard navigate while a sticky title/caption stays synced to the active item.

Built for agencies and templates that need real CMS binding — not a static image array dressed as a carousel.

### Features
- Items mapped for CMS fields: image, title, caption, tag, link
- Sticky active title + optional tag + progress
- Drag + scroll + keyboard (← → Home End)
- Snap alignment with click-guard while dragging
- Mobile-safe: `touch-action: pan-y` preserves vertical page scroll
- Respects `prefers-reduced-motion`

### Best used for
- CMS case study indexes
- Portfolio / work pages
- Product media walls

## Setup
1. Add `CMSSpotlightGallery.tsx` to your Framer Code folder
2. Bind `Items (CMS)` to your collection fields
3. Tune card width, gap, height, colors
4. Preview with real CMS content (not placeholders only)
