# Logo Marquee

**Category:** Carousels  
**Price:** Free or $5–9  
**Byline:** Infinite logo strip for trusted-by sections

## Description

Logo Marquee is a seamless infinite logo strip for “Trusted by”, partners, and press rows under a hero. Pause on hover, edge fades, optional links.

### Features
- Image + optional label + optional link per item
- Speed and Left/Right direction
- Gap and logo height
- Pause on hover
- Edge fade masks
- Seamless duplicated track
- Reduced motion → static strip (no infinite scroll)

### Not included (by design)
Drag scrubber, zoom focus, 3D curve, CMS binding.

## Setup
1. Paste `LogoMarquee.tsx` into Framer → Assets → Code
2. Replace logos in the Logos array
3. Tune speed, gap, fades

## Acceptance
- Continuous loop without visible jump (≥4 logos)
- Hover pauses when enabled
- Links work without breaking page scroll
- Single self-contained `.tsx`
