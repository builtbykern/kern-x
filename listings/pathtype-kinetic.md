# PathType Kinetic

**Category:** Typography  
**Price:** $12  
**Byline:** Path + scroll kinetic type for hero headlines

## Marketplace description

PathType Kinetic is a focused typography component for headlines that need motion. Run text along Arc, Wave, Line, or a custom SVG path — or switch to scroll-driven Color Reveal, Blur, and Scramble modes.

One component, multiple effect modes — not eight fragmented listings.

### Modes
- **Path** — text rides an SVG path (auto-loop or scroll)
- **ColorReveal** — word/letter color transition on scroll
- **Blur** — blur-to-sharp reveal
- **Scramble** — decode-style character scramble

### Features
- Letter or word granularity
- Font family, size, weight, tracking controls
- Custom SVG path string
- Auto path loop with duration
- Respects `prefers-reduced-motion`

### Best used for
- Hero headlines
- Storytelling / editorial sections
- Portfolio intros

## Setup
1. Add `PathTypeKinetic.tsx` to your Framer Code folder
2. Choose Mode + Path preset
3. Paste headline copy and tune typography
4. Keep the live preview to a single centered instance
